# Karo Frontend

Vue.js 3 + TypeScript budget management application frontend.

## Live Demo
🌐 https://jeromeboulanger12.github.io/Karo-Frontend/

## Development

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```

## Features
- 💰 Budget envelope management
- 💳 Account and bill tracking
- 👥 Multi-user household support
- 📊 Balance history charts
- 🔐 Supabase authentication

## Backend
The backend API is located in the main [Karo](https://github.com/JeromeBoulanger12/Karo) repository (private).

## Deployment
Automatically deployed to GitHub Pages on push to master via GitHub Actions.
